# Negative / exclude prompts

Use these when your tool supports negative prompts or "avoid" instructions.

```
blurry, low contrast, busy collage, photorealistic faces, stock photo models,
watermarks, logos, QR codes, tiny unreadable text, 3D glossy balloons,
cluttered mockups, multiple products overlapping, NSFW, violence,
deformed hands, extra fingers, fake UI screenshots with nonsense text
```

## Marketplace-specific avoid list

- **Etsy:** avoid trademarked brand names in the prompt (Apple, Disney, etc.)
- **Gumroad:** avoid looking like a phishing page (fake browser chrome, login forms)
