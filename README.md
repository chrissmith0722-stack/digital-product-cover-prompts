# Digital Product Cover Prompts

Prompt pack for Midjourney / DALL·E / similar tools — covers for Etsy & Gumroad digital downloads.

## Contents

- `PROMPTS.md` — reusable prompt formulas + niche examples
- `negative-prompts.md` — things to exclude
- `LICENSE` — MIT

## How to use

1. Pick a formula in `PROMPTS.md`.
2. Swap `[PRODUCT]`, `[PALETTE]`, `[STYLE]`.
3. Generate 4–8 variants; pick one readable at thumbnail size.
4. Export square (1:1) and landscape (16:9) if your marketplace needs both.
