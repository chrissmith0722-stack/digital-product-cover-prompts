# Cover Prompt Pack (Midjourney / DALL·E)

## Universal formula

```
Product cover for [PRODUCT], clean marketplace thumbnail, bold readable title text "[TITLE]",
[STYLE] illustration, [PALETTE] color palette, high contrast, ample negative space,
centered composition, no photorealistic people, no watermarks, no tiny logos --ar 1:1 --v 6
```

**DALL·E tip:** drop Midjourney flags; add "square image, sharp edges, graphic design poster".

## Style presets

| Style | Prompt fragment |
|-------|-----------------|
| Soft stationery | soft paper texture, pastel stationery, subtle grid, gentle shadows |
| Bold SaaS | flat geometric shapes, neon accent on dark navy, modern UI poster |
| Cozy planner | warm cream background, hand-drawn icons, cozy desk flatlay vibe (illustrated) |
| Minimal mono | black and white, Swiss typography feel, thick rules, stark contrast |
| Nature calm | muted sage and sand, botanical line art, calm wellness aesthetic |

## Title text tips

- Prefer 1–3 words on the image; put subtitle in listing copy.
- If the model garbles text: generate without text, then overlay title in Canva/Figma.
- Always check legibility at ~200×200 px before publishing.
